# Joel Oluwasogo — Portfolio

Professional portfolio (React + TypeScript + Vite).

## Live site (GitHub Pages)

**https://joelsogo.github.io/jay-portfolio/**

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Pushes to `master` auto-deploy via GitHub Actions → GitHub Pages.

### One-time setup (if Pages is not enabled yet)

1. Open https://github.com/Joelsogo/jay-portfolio/settings/pages
2. Under **Source**, choose **GitHub Actions**
3. Save, then re-run the workflow if needed: Actions → Deploy to GitHub Pages → Run workflow
