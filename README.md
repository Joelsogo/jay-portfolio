# Joel Oluwasogo — Portfolio

Modern mobile-first personal portfolio built with **React + Vite + TypeScript**.

Updated with latest resume content (Quality Assurance / Evaluation Specialist focus).

## Features

- Fully responsive & mobile-app feel (sticky header + bottom navigation on mobile)
- Dark theme matching previous design language
- Sections: Home, About, Skills, Experience (with full work history + education + certs), Contact
- Smooth scroll + active section highlighting
- Safe-area aware for notched devices

## Tech Stack

- React 18
- TypeScript
- Vite 5
- react-icons

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Deploy

Works great on Vercel, Netlify, or GitHub Pages (base is set to `./`).
